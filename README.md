# Lumora Studio

Lumora Studio makes creative desktop apps that run on your own computer. Its first app is
[Relight Studio AI](https://github.com/cesaressau21/relight-studio-ai).

| Folder | Contents |
| --- | --- |
| [`brand/logo`](brand/logo) | The logo kit: SVG, PNG, app icon and favicon, colors and font. See its README. |
| [`website`](website) | The studio's one-page website, published at https://cesaressau21.github.io/lumora-studio/ |

The website is deployed by [`.github/workflows/pages.yml`](.github/workflows/pages.yml) whenever
`website/` changes on `main`.
